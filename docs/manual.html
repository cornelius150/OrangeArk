一、快速入门

橙子笔记是一款树状层级笔记软件：所有笔记保存在一个文档中，文档内部以无限层级的树状节点组织内容。

  • 新建文档：菜单「文件 → 新建」，选择保存位置后即创建一个 .md 文档。
  • 打开文档：「文件 → 打开」，选择此前保存的 .md 文档即可完整恢复节点树与全部内容。
  • 自动保存：可在「工具 → 首选项」中开启自动保存，也可以随时按 Ctrl+S 手动保存。
  • 文档格式：文档是标准的 Markdown 文本文件，任何文本编辑器都能打开阅读；橙子笔记自身的数据则以内嵌快照形式无损保存，确保重开后树状结构与所有富文本格式完全一致。
💡 文档是纯文本性质的 .md 文件，方便备份、同步和版本管理，也便于迁移到其他笔记工具。加密码保存见「十一、文档与加密」。

二、节点管理

基本操作

  • 新建节点：Ctrl+N 新建同级节点；Ctrl+Shift+N 新建子节点。左栏空白处或节点上右键菜单也可以完成。
  • 重命名：选中节点按 F2，或右键 →「编辑节点」。
  • 删除节点：右键 →「删除节点」（连同其全部子节点一起删除，删除前有确认提示）。
  • 复制节点：Ctrl+Shift+D 复制当前节点（含全部子节点）。
  • 节点图标与颜色：树中每个层级的节点图标自动按深度着色（根节点橙色、子节点蓝色、孙节点绿色……依次循环）；右键 →「属性」可自定义图标与颜色。
  • 书签：右键节点 →「添加到书签」，常用节点会固定在树栏顶部，右键书签可跳转或移除。
  • 搜索：Ctrl+F 在当前节点内查找；「搜索」菜单可跨全部节点全文搜索。

移动节点

  • 拖拽：按住节点拖到目标节点上，松手即成为其子节点；拖到两个节点之间则插到它们中间。
  • 方向移动：Shift+Alt+↑/↓ 在兄弟节点间上移 / 下移；Shift+Alt+← 升一级（变为父节点的兄弟）、Shift+Alt+→ 降一级（钻入上方兄弟节点内部）。
  • 更换父节点：Shift+Alt+J，在弹出的树形对话框中点选新的父节点。
  • 排序：「树型」菜单可对整棵树或当前节点的兄弟按名称排序（支持自然排序，"第2章"排在"第10章"之前）。

节点类型

每个节点可选择三种类型：富文本（默认，本手册主要介绍）、纯文本 与 代码（整页代码编辑，带语法高亮）。

三、多选与批量移动新

v1.2.0 起左侧节点树支持一次选中多个节点，并把它们整体搬到另一个节点之下。

怎么选中多个节点

  • 点选多个：按住 Ctrl 逐个点击节点，点到的节点都会进入选中集（再点一下取消）。
  • 范围选择：先点击一个节点，再按住 Shift 点击另一个节点，两者之间的连续节点全部选中。
  • 单击（不带 Ctrl/Shift）任意节点即恢复正常单选。

批量移动到某个节点之下

  1. 按上述方法选中多个节点（一个节点也可以）。
  2. 在选中节点上右键 → 移动 → 移动所选节点到…（或菜单「树型 → 移动 → 移动所选节点到…」）。
  3. 在弹出的树形对话框中点选目标父节点，确定。
  4. 所有选中的节点立即整体搬到目标节点之下（按原顺序排在末尾）。
💡 移动会连同每个节点的全部子节点一起搬走，不需要先展开。目标节点会自动展开，方便确认结果。

批量移动的保护规则

  • 如果同时选中了父节点和它的子孙，只有父节点会被移动（子孙跟着父节点走，不会重复搬）。
  • 目标节点不能是被移动节点自己，也不能是任一被移动节点的子孙（否则会形成死循环），违反时会明确报错。
  • 目标节点就是某个选中节点当前的父节点时，该节点自动跳过（位置没变化）；如果全部节点都无需移动，会给出提示。

四、节点时间戳新

v1.2.0 起每个节点名称后面会显示一个灰色小字时间戳，即该节点的创建时间（格式 年-月-日 时:分）：

  • 自动生成：每次新建节点（Ctrl+N / Ctrl+Shift+N / 复制节点 / 导入等）都会自动记录创建时间，无需手动填写。
  • 旧文档自动补齐：用旧版本创建的文档第一次用 v1.2.0+ 打开时，没有时间戳的节点会自动补上当前时间，并在下一次保存时写进文档，之后固定不变。
  • 随文档保存：时间戳保存在文档内（ts_creation 字段），.md / 加密的 .mdz / 传统 .ctd 等格式都支持；旧版本软件打开新文档也不受影响（只是不显示）。
  • 状态栏同样会显示当前节点的「创建时间」，把鼠标悬停在节点上也能看到节点名提示。

五、富文本编辑

文字格式

  • 字体与字号：工具栏中的字体下拉框列出系统已安装的全部字体（常用中文字体排在前面）；右侧字号下拉框提供 8–72 号字号。选中文字后选择即可应用，也可以不选中文本，在光标处继续输入时生效。
  • 常用样式：加粗 Ctrl+B、斜体 Ctrl+I、下划线 Ctrl+U、删除线 Ctrl+K、等宽字体等。
  • 上标 / 下标：工具栏「x²」「x₂」按钮以上标 / 下标显示选中文字（v1.1.8 起按当前字号真实上移 / 下移）。
  • 颜色：工具栏「字体颜色」与「背景色」按钮可给选中文字上色；「高亮色」按钮提供一键荧光标记；两个按钮都带吸管取色器，可从屏幕任意位置取色。
  • 标题样式：Ctrl+1 / 2 / 3 切换一、二、三级标题。
  • 格式刷：工具栏的格式刷按钮（刷子图标）可复制上一个应用的格式，选中文字后点一下即可套用；F7 可重复上一次的格式操作，「清除格式」按钮可去掉选中文字上的所有样式。

段落与缩进

  • 支持左 / 中 / 右对齐、项目符号列表、编号列表与待办列表；编号样式库提供 10 种编号（1. / A. / a. / (一) / ① 等）。
  • 段落缩进支持 Tab 增加缩进、Shift+Tab 减少缩进；列表内 Tab 可逐级下沉。
  • 对齐、缩进、颜色、字体等全部格式随文档一起保存，导出 PDF / HTML 时同样保留。

六、表格

  • 插入表格：菜单「插入 → 表格」，设置行列数。
  • 编辑单元格：点击单元格直接输入；Tab 跳到下一格，Shift+Tab 退回上一格。
  • 调整大小：将鼠标移到表格边缘出现调整光标后拖动，即可调整宽度与高度；列分隔线可以直接在单元格内拖动（双向箭头光标）。
  • 行列操作：右键表格可插入 / 删除行列、设置列宽与对齐方式。

七、代码框

  • 插入：「插入 → 代码框」，选择编程语言后获得带语法高亮的代码编辑区。
  • 支持数十种主流编程语言的高亮，代码框内 Tab 输入缩进而非跳出。
  • 代码框可像图片一样拖拽边缘调整大小。
  • 右键代码框可修改语言、自动换行、行号显示等选项。

八、画图工具新

工具栏的「插入图形」按钮（图片按钮左侧）可在正文中插入一块可自由画图的画布，适合画流程图、拓扑图、示意图（v1.3.0 起）。

  • 拖拽画形状：选中形状工具后，在画布上按住鼠标拖动即画出矩形 / 椭圆 / 菱形等形状；单击不会生成图形。
  • 画图工具栏：点击画布区域自动显示（形状、连线、文字、字号与颜色），光标回到正文时自动隐藏。
  • 文字：双击形状可输入文字，支持设置字号与文字颜色。

连线（Visio 式）

  • 四向连接箭头：鼠标悬停在图形上时四边显示橙色三角箭头，移开即消失；单击箭头会在该方向自动生成一个同款图形并自动连线；按住箭头拖动可连到已有图形，或拖到空白处松手弹出形状菜单选择生成。
  • 自动吸附：连线两端自动吸附图形边框连接点（菱形为四条斜边的中点），拖动图形时连线跟随。

调整大小

  • 选中图形后，四角与四边的控制点可拖动缩放；鼠标放在边框线上出现双向箭头光标时，沿边线任意位置按住拖动即可调整大小，不必瞄准小控制点。
💡 画布内容随文档一起保存，导出 HTML / PDF 时按图片导出。

九、图片

  • 插入：「插入 → 图片」或直接把图片文件拖进编辑区；截图复制的图片也可 Ctrl+V 粘贴。
  • 调整大小：鼠标移到图片上出现调整光标后拖动，可放大也可以缩小；调整手柄只在悬停时显示，平时不遮挡内容。
  • 还原：右键图片 →「还原大小」可一键恢复原始尺寸。
  • 编辑：右键图片可选择旋转、另存为文件；贴图（钉在桌面上的图片）右上角有 ✕ 关闭按钮。

十、截图标注

橙子笔记内置 QQ 式截图工具，截完即标注、标注完即插入笔记。

  • 开始截图：按 Print（PrtSc）键，或点击工具栏相机图标。窗口自动最小化并稍候抓取屏幕。
  • 框选区域：按住鼠标左键拖出矩形区域，松开即完成框选。
  • 标注工具：确认前的悬浮工具条提供：矩形、椭圆、箭头、画笔、荧光笔、马赛克、文字标注（可直接输入中文）与数字序号标记。
  • 移动标注：画好的标注可以用鼠标拖动位置微调。
  • 完成：点击工具条「✔」确认后，截图先复制到剪贴板，回到笔记中 Ctrl+V 粘贴插入；也可以直接另存为文件。
💡 截图工具条的样式与操作习惯与 QQ / 微信截图一致，第一次使用即可上手。

十一、导入与导出

导出

格式说明
PDF当前节点或整个文档导出为 PDF，保留字体、颜色、缩进等富文本格式
HTML导出为带样式的网页，适合浏览器查看与分享
纯文本导出为无格式文本

菜单「文件 → 导出」可选择导出范围（当前节点 / 当前节点及子节点 / 整个文档）。

导入

支持导入外部 Markdown 文件（.md）与纯文本文件，标题层级会自动转换为节点层级（导入的节点同样自动记录创建时间戳）。

十二、文档与加密

两种文档文件

扩展名含义
.md普通 Markdown 文档，无密码
.mdz加密文档：内容打包压缩并用密码加密后的文件，打开时需输入密码
  • 给文档加密：「文件 → 另存为」时选择 .mdz 格式并设置密码；已加密文档再次保存仍保持加密。
  • 打开加密文档：双击或「文件 → 打开」选择 .mdz，在弹窗中输入密码。密码错误会提示「密码错误，请重新输入」。
  • 密保提示：加密后忘记密码无法找回， OrangeArk 是本地离线软件，没有任何服务器能帮你重置，请务必记牢密码或用密码管理器保管。
  • 性能：加密文档每次打开需要解压解密，超大文档会稍慢，属于正常现象。
⚠️ 加密文档忘记密码后内容将无法恢复，请务必妥善保管密码。
