免费开源的层级笔记软件：树状节点管理、富文本编辑、表格与代码框、截图标注，文档以 Markdown（.md）格式保存。

下载 Windows 版 查看源代码
适用 Windows 10 / 11（64 位）· 安装版与免安装绿色版 · 永久免费

功能特性

为中文用户打造的本地笔记工具，数据保存在自己手里。

🌳

树状节点

无限层级节点组织笔记，支持节点图标、书签、拖拽排序与快速搜索。

✍️

富文本

字体、字号、颜色、加粗、下划线、上下标、标题样式，还有格式刷一键复制格式。

📋

表格与代码框

可编辑表格、带语法高亮的代码框、多行缩进与列表，记录结构化内容。

📷

截图标注

内置截图工具：矩形、椭圆、箭头、画笔、文字标注与序号标记，QQ 式操作习惯。

📝

Markdown 文档

笔记保存为 .md 文档：人能直接阅读，其他 Markdown 工具也能打开。

📤

多格式导出

一键导出 PDF、HTML、纯文本，方便分享与打印。
